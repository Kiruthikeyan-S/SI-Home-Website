# 🏠 SI Home Website

A modern and responsive real-estate website designed to showcase residential properties and provide users with a simple and engaging way to explore homes.

## 📌 Project Overview

**SI Home Website** is a real-estate web design project created with a focus on **modern UI/UX, responsive design, and easy property exploration**.

The website provides users with an attractive interface to browse properties, view property details, and explore available housing options.

## ✨ Features

* 🏠 Modern real-estate homepage
* 🔍 Property exploration
* 🖼️ Property images and visual presentation
* 📋 Property information and details
* 📱 Fully responsive design
* 🎨 Clean and modern UI
* 🧭 Easy navigation
* 📞 Contact / enquiry section
* ⚡ Smooth and user-friendly interactions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 Design Goals

The main goals of this project are:

1. Create a professional real-estate website.
2. Provide a simple and intuitive user experience.
3. Present properties using attractive visual layouts.
4. Make the website responsive across different devices.
5. Apply modern UI/UX principles.

## 📱 Responsive Design

The website is designed to provide a consistent experience on:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

## 🏡 Main Sections

### Home

The landing page introduces the real-estate service and highlights the main property offerings.

### Properties

Users can explore available properties and view important information about each property.

### Property Details

Provides detailed information about a selected property along with images and relevant information.

### Contact

Allows users to get in touch for property enquiries and additional information.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Kiruthikeyan-S/SI-Home-Website.git
```

### Navigate to the Project

```bash
cd SI-Home-Website
```

### Run the Project

Open the project in **Visual Studio Code** and run it using the appropriate development server for the technologies used in the `App` folder.
